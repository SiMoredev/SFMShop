# Git Workflow для проекта SFMShop

## Использованные команды Git
- git init - инициализация репозитория
- git add - добавление файлов в staging area
- git commit - зафиксировать изменения в истории проекта
- git switch - перемещение между ветками
- git merge - слияние двух веток
- git fetch - подтянуть информацию об удаленных ветках
- git log - логи гита
- git diff - просмотр разницы между ветками
- git pull - получить актуальные изменения с удаленного репо в локальный
- git push - выгрузить изменения в удаленный репо для ПР
- git rebase - перенести коммиты одной ветки поверх другой

## Созданные ветки
- main - основная ветка проекта
- features - ветка для системы скидок

## Разрешенные конфликты
- Конфликт в src/models/product.py при слиянии features
- Конфликт в src/models/orders.py при слиянии features
- Конфликт в src/main.py при слиянии features

## Стратегия работы с ветками
- Ветка main только для релизов
- Ветка features для разработки и тестирования функционала. Удаляется после успешного ПР
